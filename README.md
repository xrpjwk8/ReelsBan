# ReelsBan

릴스·쇼츠·틱톡을 그만 넘기고, 이제 현실로.

**Chrome에서 서비스별 하루 시청 개수를 정하고, 한도에 도달하면 맥도날드 채용 공고로 자동 이동하는 확장 프로그램입니다.** 각 서비스의 한도와 사용 여부를 따로 설정할 수 있습니다.

- 기본 한도: **릴스 20개 / 쇼츠 20개 / 틱톡 20개**
- 흑백 팝업에서 한도·켜기/끄기 설정
- 한도를 채운 서비스에서만 현재 탭을 공고로 이동
- 기기 현지 시간 기준 매일 자정 이후 사용량 초기화
- 별도 회원가입·서버·빌드 없이 설치

> 데스크톱 Chrome 웹사이트용입니다. iPhone·Android의 Instagram, YouTube, TikTok 앱에는 적용되지 않습니다. Chrome 웹 스토어에는 아직 등록되지 않았습니다.

## iPhone 앱 개발 버전

`ios/`에 **iOS 26.5 이상**을 대상으로 하는 별도 SwiftUI 앱을 추가했습니다. Chrome 버전의 영상 개수 대신, 선택한 여러 앱에 각각 하루 사용 시간 한도(앱마다 기본 30분)를 적용합니다. 한도에 도달한 앱만 차단하고, **설정한 사이트 열기**를 누르면 ReelsBan 앱 안에서 사용자 지정 주소를 엽니다. 기본값은 맥도날드 공고입니다. 시간 제한 권한 승인에는 아이폰 잠금 암호가 필요합니다.

개발 소스 단계이며 App Store/TestFlight에는 배포하지 않았습니다. 설치·서명 준비, SDK 요구사항, 실기기 검증 항목은 [iPhone 개발 안내](ios/README.md)를 참고하세요.

## 1. 설치하기

1. 이 GitHub 페이지 상단의 **Code → Download ZIP**을 클릭합니다.
2. ZIP 파일을 압축 해제하고, 폴더를 계속 보관할 위치로 옮깁니다.
3. Chrome 주소창에 `chrome://extensions`를 입력합니다.
4. 오른쪽 위 **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 클릭합니다.
6. 압축을 푼 폴더 안의 **`extension` 폴더**를 선택합니다. `manifest.json`이 들어 있는 폴더입니다.
7. Chrome 툴바의 퍼즐 모양 확장 프로그램 메뉴에서 **ReelsBan을 고정**합니다.
8. 이미 열려 있던 Instagram·YouTube·TikTok 탭을 새로고침합니다.

**설치 후 `extension` 폴더를 이동하거나 삭제하지 마세요.** Chrome이 해당 폴더의 파일을 직접 읽습니다. 설치에 Node.js나 `npm install`은 필요하지 않습니다.

## 2. 하루 한도 설정하기

1. 툴바에서 **reelsban** 아이콘을 클릭합니다.
2. 인스타그램 릴스·유튜브 쇼츠·틱톡의 **하루 한도**를 각각 입력합니다. 범위는 **1~500개**입니다.
3. 필요 없는 서비스는 오른쪽 스위치를 끕니다.
4. **오늘의 약속 저장**을 클릭합니다.

예를 들어 릴스 20개, 쇼츠 10개, 틱톡 30개로 저장하면 각 서비스에 별도 한도가 적용됩니다. 릴스 한도를 채워도 쇼츠와 틱톡의 한도가 남아 있으면 계속 이용할 수 있습니다.

- 팝업: 각 서비스의 오늘 사용량과 남은 개수 표시
- 시청 화면 오른쪽 아래: 해당 서비스의 현재 사용량 표시
- Chrome 툴바 배지: 세 서비스의 오늘 사용량 합계

이미 저장한 설정은 업데이트 후에도 유지됩니다. 기본값이 20개여도 이전에 30개로 저장했다면 30개가 유지됩니다.

## 3. 어떻게 세나요?

- **첫 영상도 1개**로 계산합니다.
- 영상이 화면에 **65% 이상 보인 상태로 약 0.65초** 유지되면 집계합니다. 영상 길이가 아니라 화면에 머문 시간을 기준으로 합니다.
- 같은 영상의 반복 재생이나 미세한 스크롤은 추가로 세지 않습니다.
- 다른 영상을 본 뒤 이전 영상으로 돌아오면 다시 1개로 셉니다.
- 같은 서비스의 여러 탭에서 본 개수는 합산합니다. 다른 탭에서 같은 영상을 보는 것은 별도 시청입니다.
- 백그라운드 탭은 집계하지 않습니다.
- 자정 이후 다음 확인 때 횟수만 초기화되고, 한도 설정은 유지됩니다.

| 서비스 | 집계 대상 | 제외 대상 |
|---|---|---|
| Instagram | `/reel/…`, `/reels/…` 시청 화면 | 홈 피드, DM, 스토리 |
| YouTube | `/shorts/영상ID` 시청 화면 | 일반 영상, 홈·검색 목록 미리보기 |
| TikTok | 추천·팔로잉 피드, 개별 동영상 시청 화면 | LIVE, 사진, 검색·프로필 목록, 식별할 수 없는 영상 |

틱톡은 **로그인 없이도 집계**합니다. `/ko-KR/` 같은 언어 경로와, 영상 링크가 없는 비로그인 추천 카드도 지원합니다. 별도 플로팅 플레이어는 지원 범위에 포함하지 않습니다.

## 4. 한도에 도달하면

영상 재생을 멈추고 **현재 탭이 채용 공고로 자동 이동**합니다. 중간 안내 화면이나 확인 버튼은 없습니다. 한도를 채운 뒤 같은 서비스를 다시 열어도 이동합니다.

| 위치 확인 결과 | 이동할 공고 |
|---|---|
| 서울로 확인됨 | [서울 공고](https://mcdonalds.recruiter.co.kr/career/jobs/120676) |
| 서울 외 / 위치 권한 없음 / 위치 확인 실패 | [기본 공고](https://mcdonalds.recruiter.co.kr/career/jobs/130416) |

- **위치 권한을 새로 요청하지 않습니다.** 해당 사이트에 위치 접근이 이미 허용된 경우에만 확인합니다.
- macOS 위치 서비스가 켜져 있어도 사이트 권한이 없으면 기본 공고로 이동합니다. Instagram의 허용 상태는 YouTube·TikTok에 자동 적용되지 않습니다.
- 권한이 없으면 위치 조회를 건너뜁니다. 이미 허용된 경우에도 최대 2.5초 확인 후 실패하면 기본 공고로 이동합니다.
- 가장 가까운 매장이나 현재 모집 중인 공고를 검색하는 기능은 아닙니다. 위 두 고정 링크를 사용하므로 공고가 마감될 수 있습니다.

제한을 풀고 싶다면 팝업에서 해당 서비스의 한도를 높이거나 스위치를 끄고 **저장**하세요. 저장한 사용량은 지워지지 않습니다.

## 5. 업데이트하기

1. 최신 ZIP을 내려받아 압축을 풉니다.
2. 기존 설치 경로의 `extension` 폴더를 최신 파일로 갱신합니다.
3. `chrome://extensions`에서 ReelsBan의 **새로고침** 버튼을 누릅니다.
4. 열려 있던 세 서비스의 탭도 새로고침합니다.

같은 설치 경로와 확장 항목을 유지하면 설정·기록도 유지됩니다. 기존 확장을 삭제하면 저장된 기록이 지워질 수 있습니다.

## 6. 문제가 생겼나요?

**숫자가 올라가지 않아요.**

- 확장 프로그램과 해당 서비스의 스위치가 켜져 있는지 확인하세요.
- `chrome://extensions`의 ReelsBan 상세 화면에서 해당 사이트에 대한 접근이 허용되어 있는지 확인하세요.
- 업데이트했다면 확장 프로그램과 웹사이트 탭을 모두 새로고침하세요.
- 위 표의 집계 대상 화면에서 영상을 약 1초씩 보며 넘겨 보세요. 검색·프로필 미리보기는 제외됩니다.

**서울인데 기본 공고로 이동해요.**

해당 사이트의 위치 권한이 없거나 위치 확인이 실패하면 정상적으로 기본 공고로 이동합니다. 위치 오차와 서울 경계 데이터에 따른 오차도 있을 수 있습니다.

**새로고침하자마자 공고로 이동해요.**

오늘 한도를 이미 채운 경우입니다. 팝업에서 한도를 높이거나 해당 서비스의 스위치를 끄고 저장하세요.

**사이트 개편 후 집계가 이상해요.**

각 사이트의 URL과 화면 구조를 읽는 방식이어서 UI 변경이나 광고 등에 따라 누락·중복이 생길 수 있습니다. 문제를 보고할 때 서비스명, 로그인 여부, 페이지 경로, 재현 순서를 알려 주세요. 계정 정보나 개인 시청 기록은 공유할 필요가 없습니다.

## 개인정보와 권한

- 확장 권한: `storage`, Instagram·YouTube·TikTok의 지정된 웹사이트에서 스크립트 실행
- 저장 항목: 날짜, 서비스별 한도·사용량·활성 상태, 탭별 마지막 영상 식별자
- 저장 위치: 해당 Chrome 프로필의 `chrome.storage.local`
- 별도 서버 전송·분석 도구·계정 연동 없음
- 위치 좌표는 메모리에서 서울 여부만 판별하며 저장하거나 외부 지오코딩 서버로 전송하지 않음. 브라우저 자체 위치 서비스는 별도
- 서울 경계 데이터 출처·이용 조건: [DATA-SOURCES.md](DATA-SOURCES.md)

확장 비활성화나 다른 브라우저로 우회할 수 있는 자발적 습관 관리 도구입니다. Instagram, YouTube, TikTok, McDonald's와 제휴하거나 이들의 승인을 받은 제품이 아닙니다.

## 개발 및 검증

개발 테스트에는 **Node.js 22 이상**을 권장합니다. 외부 npm 패키지는 사용하지 않습니다.

```sh
npm test
npm run test:browser:all
```

브라우저 검증은 macOS Chrome을 임시 프로필로 실행합니다. 다른 설치 경로는 `CHROME_BIN` 환경변수로 지정하세요. 모의 페이지에서 집계·중복 방지·자동 이동·설정 반영·페이지 전환을 확인하며, 공고로의 실제 이동과 실제 위치 조회는 하지 않습니다. 틱톡 비로그인 페이지 구조도 별도로 검사합니다.

실사용 확인은 각 서비스의 한도를 3개로 저장한 뒤, 약 1초씩 영상을 넘겨 **해당 서비스 숫자만 증가하고 3개에서 공고로 이동**하는지 확인하면 됩니다. 자동 검증은 모든 계정·지역·사이트 UI에 대한 동작 보장을 의미하지 않습니다.

### 파일 구성

- `extension/` — Chrome에 설치할 확장 파일
- `tests/` — 상태·권한·영상 감지 및 모의 브라우저 테스트
- `DATA-SOURCES.md` — 서울 경계 데이터 출처

이 저장소의 공개는 소스 열람·설치 공유를 위한 것입니다. 별도의 오픈소스 라이선스는 아직 지정하지 않았으며, 포함된 경계 데이터에는 출처의 이용 조건이 적용됩니다.
